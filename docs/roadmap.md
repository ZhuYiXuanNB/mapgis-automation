# 路线图：从脚本到 MCP

目标：让 AI 能可靠地"操作 MAPGIS 出图"，最终变成一组语义工具，而不是一堆坐标点击。

## 阶段 0 · 已完成（脚本化）

用 `scripts/drv.ps1` + 少量专用脚本，跑通：

```
.det 数据 → 离散数据网格化(.GRD) → 平面等值线图 → 4 级阈值 + 白底三色
          → 存 WT/WL/WP → 新建工程 → 加图层 → 复位窗口
          → 工程输出 → 页面设置(自动幅面) → 生成 JPEG (300dpi)
```

产出过 6 张图（3 元素 × 2 套分带倍率），单张耗时约 8–10 分钟（多数时间在等待绘图）。

## 阶段 1 · 抽象成库

把动作从"字符串步骤"提升为函数，供脚本直接调用：

- PowerShell module `MapGisAutomation`：`Open-Grid`、`Set-Levels`、`Set-BandColors`、`Save-Layers`、`Export-Jpeg`
- 或 Python `ctypes` 实现（便于和 MCP server 同语言）

要点：
- 每个动作返回结构化状态（窗口句柄、当前层值、当前颜色、是否成功），而不是只靠截图
- 幂等：重复调用不破坏已有状态
- 统一超时与重试

## 阶段 2 · MCP server

对模型暴露这些工具（参数尽量语义化）：

| 工具 | 参数 | 说明 |
|---|---|---|
| `mapgis_open_grid` | grd 路径 | 打开网格并进入等值线设置 |
| `mapgis_set_levels` | `[v1,v2,v3,v4]` | 设等值层值 |
| `mapgis_set_band_colors` | `[{rgb},…]` | 设区参数（含白色背景） |
| `mapgis_draw` | — | 确定并绘制，返回耗时 |
| `mapgis_save_layers` | `{wt,wl,wp}` | 存点线面 |
| `mapgis_build_project` | `{mpj, layers[]}` | 建工程 + 加图层 + 保存 |
| `mapgis_export_jpeg` | `{dpi}` | 工程输出 → JPEG |
| `mapgis_screenshot` | `{path}` | 当前窗口截图（调试用） |

资源（resources）：当前工程、当前图层列表、最近一次出图路径。

底层仍走 Win32，但对模型来说只需要"给阈值、给颜色、要图"。

## 阶段 3 · 稳定化

当前最大的脆弱点全是坐标：

- **视觉定位**：用模板匹配（OpenCV `matchTemplate`）找按钮/色块，替代固定坐标
- **OCR**：读取对话框里的层值、色号，做断言（现在靠人眼截图）
- **状态机**：把"当前在哪个模式（编辑/输出/绘图）"显式建模，避免"点了没反应"时的盲目重试
- **失败恢复**：识别模态框、重启进程、重建工程

## 阶段 4 · 绕开 GUI（最有价值的方向）

1. **直接读格式**：`.GRD` 已摸清 —— 头部 `DSBB`，偏移 4 两个 int16 为 nx/ny，偏移 8 起 5 个 double（xmin,xmax,ymin,ymax,nodata），56 字节头之后是 `nx*ny` 个 float32（行序自 ymin）。
   点/线/区 `.WT/.WL/.WP` 为 MAPGIS 自有二进制，需要逆向或用官方接口转换。
2. **导出交换格式**：用 MAPGIS 自带的"输出数据转换"导 DXF / ArcInfo Coverage，再由 GDAL 读取。
3. **MX 二次开发**：MAPGIS 6.7 有 MX 组件（ActiveX），比 GUI 稳定得多；若许可允许，优先走这条路。
4. **只借它做网格化**：网格化（距离幂函数反比加权）用 MAPGIS，成图交给 GDAL/QGIS/Matplotlib —— 可控、可版本化、能进 CI。

## 阶段 5 · 终局形态

```
输入：采样点 CSV + 元素 + 阈值方案
输出：白底分级异常图（矢量 PDF/PNG）+ 图层文件 + 统计表
```

- 图由代码生成，可复现、可比较、可批量
- MAPGIS 只承担"它独有的算法/格式"部分，且尽量通过文件接口而非 GUI 交互
- GUI 自动化退化为"兜底手段"，只在必须人工介入的步骤使用

## 已知未解问题

- `.WT/.WL/.WP` 二进制结构未完整解析（能从 MAPGIS 内部导出，但外部生成困难）
- 大网格（> 500×500）绘图与出图耗时显著，超时策略需要按数据量自适应
- DPI 缩放 / 多显示器下窗口矩形需要重新校准
- 加密狗与并发：同一时间只允许一个 MAPGIS 实例操作
