# 窗口与命令速查（MAPGIS 6.7，实测）

## 进程

| 进程 | 用途 | 主窗口类 |
|---|---|---|
| `W60_DTM.exe` | 空间分析：网格化、等值线、存数据 | `Afx:...`（MFC） |
| `mdiedit6x.exe` | 输入编辑：建工程、加图层、工程输出 | `Afx:...`（MFC） |
| `mapout60.exe` | 输出子系统（光栅/PS） | `Afx:...` |
| `DogServer67.exe` | 加密狗服务，需先启动 | — |

## 常见窗口

| 标题 | 类 | 说明 |
|---|---|---|
| `打开文件` / `MAPGIS 打开文件` | `#32770` | 文件选择，文件名框 id=1152，类型下拉 id=1136 |
| `设置等值线参数` | `#32770` | 层值列表 id=3620，删除一层 id=3611，套区 id=3601，色阶 id=3608，区参数列表头 id=3606，层值列 id=3604 |
| `编辑等值线层值` | `#32770` | 只有一个输入框 id=101 |
| `选择颜色` | `#32770` | 色盘 id=102，滚动条 id=103，当前色号 id=101，R/G/B 为 1293/1294/1295，CM/YK 为 1289/1290/1291/1292 |
| `设置输出位图的分辨率` | `#32770` | 分辨率输入 id=1005，RGB 模式 id=1006，CMYK id=1007 |
| `工程输出编辑` | `#32770` | 版面定义下拉 id=1162，确定 id=1，取消 id=2 |
| `错误警告` | `#32770` | **隐藏**模态框，按钮 id=1（OK），必须点掉 |

## 命令 ID

### W60_DTM

| ID | 功能 |
|---|---|
| 32946 | 平面等值线图绘制（Grd 模型 → 平面等值线图绘制） |
| 32804 / 32805 / 32806 | 存点 / 线 / 区数据文件 |
| 32787 / 32954 | 复位窗口 / 缩小窗口 |

### mdiedit6x（编辑模式）

| ID | 功能 |
|---|---|
| 57600 | 新建工程 |
| 32851 | 打开工程或文件 |
| 113 / 101 / 107 | 工作区 → 装入点 / 线 / 区文件 |
| 32780 | 工程输出（切到输出模式；**需先复位窗口**） |

### mdiedit6x（输出模式）

| ID | 功能 |
|---|---|
| 32771 | 文件 → 页面设置 |
| 40002 / 40003 | 光栅化处理 / 设置光栅化参数 |
| 40004 | 打印光栅文件 |
| 40015 / 32795 / **32982** | 生成 GIF / Tiff / **JPEG 图像** |
| 32791 | 返回编辑 |
