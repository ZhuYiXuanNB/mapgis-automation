# MAPGIS 6.7 原生文件字节结构（.WT / .WL / .WP）

> 偏移均 0 基、小端，单位字节。A 侧偏移为 2026-11 在 Windows 10 + MAPGIS 6.7 上逐字节验证；B 侧为项目实测补全。
> 记号：`OFF` = 索引区起点（读头部 12–15 的 int32；实测三份样本都是 657，但**要读不要写死**）；数据区从 `OFF + 160` 开始。
> **⚑ 冲突标记**：两份原始记录不一致处就地标注；2026-11-26 用真实文件逐项复测，已裁决的写实测值，未裁决的保留双方说法（汇总见 §九）。

## 区段地图（总表）

索引区 16 项 × 10 B = 160 B，每项 `<int32 start><int32 size><u16 0xFFFF>`。`OFF` = 657 时的顶层布局：**0–656 文件头 / 657–816 索引区 / 817 起数据段**。**每一段起点 = 上一段终点，最后一段收尾 = 文件长度。**

| 段 | .WT 点 / 注记 | .WL 线 | .WP 区 |
|---|---|---|---|
| 0 | 坐标/点记录区 93 B ×(n+1) | 线索引 57 B ×(m+1) | 弧索引 57 B |
| 1 | 文本池：纯点 2 B；注记 1602 B + Σ文本 | 坐标区：2 B 前导 + 16 B ×Σ顶点 | 坐标（含结点表），2 B 前导 |
| 2 | 属性区（三类共用） | 属性区 | 未覆盖 |
| 3 | 定位框段 32 B ×(n+1) | 结点表 24 B ×(m+1)（实测 `500m小格线.WL` 全零，带拓扑的线才可能有值） | 拓扑 24 B |
| 4 | 标志段 4 B + 4n | 附加表 A：55 B 固定块（实测全零，整块搬） | 未覆盖 |
| 5 | — | 附加表 B：392 B 元数据（实测 52 B 非零，与属性前缀同族：`D` + 年份 + 路径） | 未覆盖 |
| 6 | — | 定位框（框表）32 B ×(m+1) | 未覆盖 |
| 7 | — | 标志段 4 B + 4m | 未覆盖 |
| 8 | — | — | 区参数 40 B |
| 9 | — | — | 属性（变长） |
| 10 | — | — | 区标注框 32 B + 32n |
| 11 | — | — | 未覆盖 |
| 12 | — | — | 文件脚 4 B + 4n |
| 13–15 | — | — | 未覆盖 |

> n = 点/注记图元数，m = 线段数。「未覆盖」= 输入没有给出该段编号或结构，不做推测；段号空缺（如 .WT 只用 0–4）即该类型未用该段。

## 一、文件头（0–335）

| 偏移 | 类型 | 含义 |
|---|---|---|
| 0–7 | char[8] | 魔数（8 字节，照抄字节别重打）：点 ``WMAP`D22``、线 ``WMAP`D21``、面 ``WMAP`D23`` |
| 8–11 | int32 | 类型字节：点 = 1 / 线 = 0 / 面 = 2 |
| 12–15 | int32 | 索引区起点 `OFF` |
| 109 | u8 | 投影类型（0 = 经纬度、5 = 高斯、2 = aea、3 = lcc） |
| 110 | u8 | 椭球号（1 = 克氏、2 = 西安 80、7 = WGS84、16 = 克氏） |
| 143–150 | f64 | 比例尺分母 |
| 244–251 / 252–259 | f64 ×2 | 毫米→度系数；为 0 时符号尺寸归零、全图不显示 |
| 260 | u16 | 图元数 n（**写新文件必改**）。有文档记为 u32；n ≤ 65535 时两种读法字节完全相同（见 §九.1） |
| 264 | u16 | 记录数 = n + 1（含首条空记录）**必改**。同上，见 §九.1 |
| 304–335 | f64 ×4 | 图幅边界 xmin / ymin / xmax / ymax，**必改**（按实际范围 ± 余量；不改缩放定位会跑到模板范围） |
| 336 | u8 | 类型标志（点 0x80、线 0） |

> 结论：**头要从真实文件克隆**。自己拼的头常差在 244/252 与 304 上，MapGIS 不报错但不出图。

## 二、.WT 点 / 注记

| 索引 | 内容 | 大小 |
|---|---|---|
| 0 | 坐标/点记录区，首条为空 | 93 × (n+1) |
| 1 | 文本池 | 纯点 2 B；注记 1602 + Σ文本字节 |
| 2 | 属性区 | 322 + 8 + 18 + 39×字段数 + 记录长×(n+1) |
| 3 | 定位框段（首条空） | 32 × (n+1) |
| 4 | 标志段 | 4 + 4n |

### 点记录（93 B）

| 偏移 | 类型 | 含义 |
|---|---|---|
| 0 | u8 | 1 = 有效 |
| 7 / 15 | f64 | X / Y（图面单位 mm） |
| 31 | u8 | 1 = 实心点 |
| 33 | i16 | 子图号（注记记录同址放 f32 字高，靠 @31 = 0/1 区分）。≤255 时 u8 / i16 字节等价；本库按 i16 读写，>255 未实测 |
| 37 / 41 | f32 | 符号高 / 宽 mm |
| 45 | f32 | 旋转角 |
| 49 | f32 | 笔宽 |
| 51 / 53 | u8 | 西文字体 / 字形 |
| 75 | u8 | 颜色号 |
| 83 | u8 | 图层号 |

### 注记记录（93 B，同一记录区）

| 偏移 | 类型 | 含义 |
|---|---|---|
| 0 | u8 | 1 = 有效 |
| 1 | u16 | 文本长度（GBK **字节数**，不是字数） |
| 3 | u32 | 文本在池内的偏移 |
| 7 / 15 | f64 | X / Y（文字锚点 = 左下角） |
| 31 | u8 | 0（注记种类标记） |
| 33 / 37 | f32 | 字高 / 字宽 mm |
| 41 | f32 | 字间距 mm |
| 45 | f32 | 旋转角（竖排用 90） |
| 49 / 51 / 53 | u8 | 中文字体 / 西文字体 / 字形 |
| 75 / 83 | u8 | 颜色 / 图层 |

> 同一个 @33 两种解释：点子图号（i16）与注记字高（f32）重叠，靠 @31 的点种类区分。

### 文本池

```
[0 .. 1601]   1602 B 样式前缀（克隆真实文件；两份真实样本仅 68 字节不同）
[1602 ..]     GBK 文字首尾相接
```

- 1602 是**固定前缀长度**，不是「首条偏移」：`地质.WT` 池 1855 B（27 条、253 B 文字）、`图框.WT` 池 1923 B（138 条、321 B 文字），字符串区都恰好从 1602 开始。
- **偏移是池内绝对位置**：实测 `图框.WT` 首条注记 `off = 1602`（若从 1602 起算，首条应为 0），池 1923 B = 1602 + 321 B 文字。
- 池长校验：注记池 = 1602 + Σ文字字节数。
- Section 方言另有一套：文本池从 **+2** 起、单条 6 字节。判据：池首偏移 2 = Section，1602 = 原生（见 `pitfalls.md`）。

### 定位框（标注框）

- 每项 4 个 f64：`(xmin, ymin, xmax, ymax)`，共 32 B × (n+1)，首条为空。
- 注记框**实测**（`图框.WT`，10 字、字宽 2.0 mm）：`(x, y−0.35h, x+17.80, y+0.93h)`——宽 ≈ **0.89 × 字数 × 字宽**。
  本库按 `vis × 字宽 × 1.05` 估算，偏宽约 18%；只影响拾取框，不影响显示位置。
- 缺失或全零 → MapGIS 可能「能读不显示」。

## 三、.WL 线

| 索引 | 内容 | 大小 |
|---|---|---|
| 0 | 线索引区 | 57 × (m+1) |
| 1 | 坐标区（2 B 前导） | 2 + 16 × Σ顶点数 |
| 2 | 属性区 | A 实测 348 + 39 + 5×(m+1)（1 字段、单记录 5 B）；B 记「变长，1 条」 |
| 3 | 结点表（实测全零） | 24 × (m+1) |
| 4 | 附加表 A（55 B 固定块，实测全零） | 整块搬运 |
| 5 | 附加表 B（392 B 元数据） | 整块搬运 |
| 6 | 定位框（框表） | 32 × (m+1) |
| 7 | 标志段 | 4 + 4m |

> 附加表 A/B 内部格式无文档，**整块搬运**：图元数量与模板同量级时可用，差别很大时要实测。段 4、5 大小固定（55 B / 392 B），与图元数无关。

### 线索引（57 B）

| 偏移 | 类型 | 含义 |
|---|---|---|
| 0 / 1 | u8 | 恒 1 / 恒 2 |
| 10 | int32 | 顶点数 |
| 14 | int32 | 坐标在坐标区内的偏移（首条 = 2） |
| 22 | i16 | 线型号；@24 = i16 辅助线型号。实测 `500m小格线.WL`：型号 2、辅助 0（int32 读法在 ≤32767 时字节等价） |
| 26 | i16 | 线颜色号（实测 1；@28 为 0，int32 读法同样成立） |
| 30 | f32 | 线宽 mm |
| 35 / 39 | f32 | X / Y 系数（线型图案比例）。**实测 1.0**；「@34 / @38 备用 f32 = 10.0」的说法与实测不符（按 @35 / @39 读正好 1.0） |
| 43 / 47 / 48 | i16 / u8 / u8 | 辅助色 / 图层 / 透明（无独立样本，仍未裁决；「@42 / @46 为 int32 1 与 20」待验） |

> 线型号取值（B）：1 = 实线，2 = 虚线/加密网常用。

### 坐标区

```
[0..1]    2 B 前导（必须存在；首条线的坐标偏移 = 2）
[2..]     每对 <f64 X><f64 Y>，按线索引顺序紧密排列
```

## 四、.WP 区（摘要）

| 索引 | 内容 | 记录长 |
|---|---|---|
| 0 | 弧索引 | 57 |
| 1 | 坐标（+ 结点表） | 2 B 前导 |
| 3 | 拓扑 | 24 |
| 8 | 区参数 | 40 |
| 9 | 属性 | 变长 |
| 10 | 区标注框 | 32 + 32n |
| 12 | 文件脚 | 4 + 4n |

- 拓扑 24 B：`[i32 结点 a][i32 结点 b][i32 左区][i32 右区][8 B 0]`，区号从 1 起。
- 区参数 40 B：`kind@0 = 1`、**类码 @1 = 图层（0 不显示）**、填充色 @5、图案 @6、图案色 u16 @9。
- **段 10、12 缺失 → 区能解析但永不渲染**（实测）。

## 五、属性表（三类文件共用）

```
[0..321]     322 B 前缀（整块克隆，不要手工拼）
[322]        i16 字段数 nf
[324]        i32 记录数 nr = 图元数 + 1
[328]        i16 记录长 rl
[330..347]   18 B 填充
[348..]      39 B × nf 描述符
[348+39nf..] 记录区：nr × rl（首条为空）
```

- **实测前缀**：首字节 `0x60` + `D`（签名），@2 起 2 字节年份（`图框.WT` = `0x07E5` = 2021），@20 起 GBK 路径（`E:\共享\…`）或表名（本库写出 `E:\GEOCHEM_MAP`）。整块克隆，不要解析。
- **记录长 `rl` 必须等于 `1 + Σ各字段存储宽度`**；对不上 → MapGIS 里字段整体错位。
- 记录首字节：`0x01` = 有效；串右补 `\0`。

### 字段描述符（39 B，`<20sBihhih4x`）

| 偏移 | 类型 | 含义 |
|---|---|---|
| 0–19 | char[20] | 字段名（GBK，`\0` 结尾） |
| 20 | u8 | 类型：0 串 / 1 byte / 2 short / 3 int32 / 4 float / 5 double / 6 日期 / 7 时间 |
| 21 | int32 | 记录内偏移，**从 1 起算**（第 0 字节是 0x01 标志） |
| 25 | i16 | 存储宽度 |
| 27 | i16 | 声明 / 显示宽度。实测 `图框.WT` 的 int32 字段 `ID` 此处 = 8——整数没有小数位，故判为声明宽度 |
| 29 | i32 | 标志：串 = 256，数值 = 512（B：512 + 小数位；A 实测 double = 518） |
| 33 | i16 | 字段序号 |

- 字符串占「宽度」字节、以 `\0` 收尾；存储偏移从 1 起算。

## 六、坐标范围与显示

- 范围写在头部 304 起 4 个 double；不改会让缩放定位跑到模板的范围。
- 244/252 两组「毫米→度系数」为 0 → 符号尺寸归零、点线面全不显示。
- 头 336 的类型标志：点 0x80、线 0。
- MapGIS 按**文件名**缓存已装入图层：磁盘文件改了要「移除图层 → 添加文件 → 复位窗口」，否则看到的还是旧图。

## 七、文本与下标

- 文本按 **GBK** 存，长度是字节数不是字数；字段名与字符串值同为 GBK。
- `#-` 是下标控制符：`A#-1` 显示为 A₁，且 `#-` 不占字宽。
- `A_1` / `A^1` / `A#1` 都会原样画出，别用。
- 定位框实测 ≈ 0.89 × 字数 × 字宽；本库按 ×1.05 估算（偏宽但安全）。

## 八、校验清单

- 魔数对不对（`.WT` = ``WMAP`D22``）；模板必须同类型（点用 `.WT`、线用 `.WL`）。
- `n = idx0.volume / 记录长 − 1`；首条记录是否为空。
- 属性 `nr == n + 1`、`rl == 1 + Σ宽度`。
- 注记：文本池 `= 1602 + Σ文字字节数`；框表 `(n+1)×32`；标志 `4 + 4n`。
- 头部 244/252 非零、304 边界框非零、260/264 与真实图元数一致。
- 段与段首尾相接、末段收尾 = 文件长度。

## 九、实测裁决（2026-11-26）

用三个真实文件逐项复测：`图框.WT`（2021 年下发件，138 条注记 / 1 个 int32 字段）、
`500m小格线.WL`（43 条线）、`控制点_合并.WT`（本库生成，2220 点 / 8 字段）。

| # | 争点 | 实测 | 结论 |
|---|---|---|---|
| 1 | 260 / 264 是 u16 还是 u32 | 138/139、43/44、2220/2221；262、266 恒 0 | n ≤ 65535 时两种读法**字节完全相同**，无法区分；本库按 u16 读写 |
| 2 | 点记录 @33 是 u8 还是 i16 | 子图号 48 / 84，高字节恒 0 | ≤255 等价；本库按 i16 读写（>255 未实测） |
| 3 | 注记池偏移基准 | 首条 `off = 1602`，池 1923 = 1602 + 321 B | **池内绝对位置**（若相对 1602，首条应为 0） |
| 4 | 注记框宽 | 10 字 / 字宽 2.0 mm → 框宽 17.80 mm | ≈ 0.89 × 字数 × 字宽；1.05 的估算偏宽 18% |
| 5 | 线索引 @35 / @39 | 两组均 `00 00 80 3f` | **f32 = 1.0**，X / Y 系数；「@34 备用 10.0」不成立 |
| 6 | 字段描述符 @27 | `ID`（int32）处 = 8、标志 = 256 | **声明宽度**，不是小数位 |
| 7 | 322 B 前缀 | `60 44` + 年份 `07 E5`(2021) + `E:\共享\…`；本库写 `E:\GEOCHEM_MAP` | 签名 + 年份 + GBK 路径/表名，整块克隆 |

仍未裁决：线记录 @43 / @47 / @48（没有图层或透明度变化的样本）、`.WP` 全部段、
子图号的 Slib 语义（`1` / `48` / `84` 的形状随机器变，只能用目视确认）。
