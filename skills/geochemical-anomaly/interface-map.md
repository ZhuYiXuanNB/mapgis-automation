# MAPGIS 6.7 界面地图（窗口 / 菜单 / 控件）

配合 `SKILL.md` 第 2 节使用。坐标是 1920×1080、100% 缩放下实测值，换分辨率需按比例换算；
**对话框的控件坐标每次都会变，必须用 `GetWindowRect` 实时取**。

## 一、窗口结构

```
主框架 (Afx:400000:...)
├── 菜单栏         y ≈ 32
├── 工具栏         图标：新建/打开/保存/编辑/查询/缩放
├── 左侧停靠窗格    x 0~185，"文件列表"（工程模式为项目栏：文件名 | 图标 | 说明）
├── MDI 客户区
│   └── 图形子窗口 (MDI child)  标题栏含文件名，内部 X/Y 标尺
└── 状态栏        当前状态 | 坐标 | 显示比例 | 当前图层
```

## 三、常用对话框控件 ID

| 对话框 | 控件 |
|---|---|
| 打开文件 / MAPGIS 打开文件 | 文件名 `1152`、类型下拉 `1136`（0=图形文件, 1=点, 2=线, 3=区…）、打开 `1`、取消 `2` |
| 设置等值线参数 | 层值列表 `3620`、删除一层 `3611`、添加一层 `3610`、等值线套区 `3601`、绘制色阶 `3608`、线参数列表头 `3605`、区参数列表头 `3606`、装设置 `3612`、确定 `1` |
| 编辑等值线层值 | 输入框 `101` |
| 编辑等值线线参数 | 线型 `1056`、线颜色 `1057`、线宽 `1058`、确定 `1` |
| 选择颜色 | 色盘 `102`、滚动条 `103`、当前色号 `101`、R/G/B `1293/1294/1295`、确定 `1` |
| 定制新建项目内容 | 不生成可编辑项 `1011`、确定 `1` |
| 工程输出编辑（页面设置） | 版面定义下拉 `1162`（0=自定义, 1=**系统自动检测幅面**, 2=A0…）、确定 `1` |
| 设置输出位图的分辨率 | 分辨率 `1005`、RGB `1006`、CMYK `1007`、确定 `1` |
| 选择叠加文件 | 叠加文件1 `1000`、叠加文件2 `1001`、说明 `1003`、确定 `1` |
| 选择属性类型 | 列表 `1000`、确定 `1` |
| 保存 / 另存 文件 | 文件名 `1152`、保存 `1`、取消 `2` |
| 换名存文件（工程） | 文件名 `1001`、保存 `1` |
| 确认另存为（覆盖提示） | 是/否按钮 **id 都是 0**，只能按坐标点 |

## 四、弹窗与提示

| 标题 | 说明 |
|---|---|
| `错误警告`（**隐藏**）| 「MapGis多用户服务器工作不正常…」，`IsWindowVisible=false` 但会吞命令；`btn:1` 点掉 |
| `请选择网络卡(狗)…` | 狗服务没起来；点取消可进主界面 |
| `MAPGIS`（是/否/取消）| 关闭绘图窗口时问是否保存；`7`=否 |
| `确认另存为` | 覆盖确认，是=左钮（约 1305,701）、否=右钮（1379,701），坐标随对话框位置变 |

## 五、右键菜单

**图形窗口右键**（与"复位窗口"同处，顺序固定）：
放大窗口 / 缩小窗口 / 移动窗口 / **更新窗口** / 上级窗口 / **复位窗口** / 清除窗口 / 窗口参数

**项目栏右键**（工程模式）：
添加项目 / 新建点线区网 / 属性 / 修改地图参数 / 全选 / 保存工程 / 另存工程 / 清空工程 / 重新显示工程 / **工程输出编辑** / 图例相关

> 两条右键菜单的弹窗位置跟随鼠标，**每次都要重新截屏定位**，不要沿用上次坐标。
