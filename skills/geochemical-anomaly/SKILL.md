# MAPGIS 6.7 化探数据处理全流程

从原始采样点表到"报告可用成果图 + 异常参数表"，全部在 MAPGIS 6.7 桌面端完成，
可用 Win32 脚本驱动（见 `scripts/`）。每步给出菜单路径、命令 ID、窗口位置与坑。

---

## 0. 环境与安装位置

| 项 | 位置 |
|---|---|
| 主程序目录 | `C:\mapgis67\program\`：`mdiedit6x.exe` 编辑、`W60_DTM.exe` DTM、`W60_Anly.exe` 空间分析、`mapout60.exe` 输出 |
| 加密狗服务 | `D:\programfiles\MapGIS6.7 051118\MAPGIS6.7\DogServer67.exe` |
| 系统库 | `C:\mapgis67\Slib`、`Slib5000`、`SuvSlib` |

**启动顺序**：先 `DogServer67.exe`，再启各子系统。
狗服务没起来时启动会弹「请选择网络卡(狗)所在的计算机名或IP地址」，取消也能进主界面，但部分命令会失效。

**必要条件**：屏幕必须解锁（`LockApp.exe` 存在时键鼠注入无效），运行期间别动鼠标。

## 1. 工作目录约定

MAPGIS 对中文长路径支持很差，**所有中间文件放根目录下的短英文路径**，如 `C:\ws`。

```
C:\ws\
├── *.det                 # 三列数据（NotGrid 表头）
├── *.GRD                 # 网格化结果，一元素一个
├── *.WT / *.WL / *.WP    # 点 / 线 / 面图层
├── *.MPJ                 # 工程文件（工程名 = 输出 JPG 名）
└── *.JPG                 # 工程输出成果
```

**工程名决定输出文件名**（`WB.MPJ` → `WB.JPG`），所以直接起成成果名。

## 2. 界面布局

### 2.1 主框架（三个子系统通用）

```
┌ 菜单栏 y≈32 ──────────────────────────────┐
├ 工具栏（保存/打开/编辑/查询/缩放）           │
│  左侧：文件列表（工程模式为"项目栏"）   右侧：竖排缩放条
│  文件树：文件名 / 图层图标 / 说明       （放大/缩小/1:1/复位）
├ 图形窗口（MDI 子窗口，带 X/Y 标尺）          │
└ 状态栏 ───────────────────────────────────┘
```

状态栏从左到右：**当前状态**（`选择区`/`删除区`/`合并区`/`处于准备状态`）、坐标、**显示比例**、**当前图层**（`[点](启用)` / `[区](启用)` / `无当前图层`）。

> 能不能做区编辑，**先看状态栏的"当前图层"**：显示 `[点]` 时选区/删区都作用在空的点层上，点了不会有反应。

### 2.2 各子系统菜单栏

**编辑子系统 `mdiedit6x`**
- 工程窗口激活：`文件 / 数字化 / 线编辑 / 区编辑 / 点编辑 / 矢量化 / 其它 / 图层 / 系统库 / 检查 / 设置 / 窗口 / 工程输出 / 帮助`
- **图形窗口激活**：`文件 / 工作区 / 数字化 / …` ← 多出 `工作区`，区文件操作全靠它

**DTM `W60_DTM`**：`文件 / 窗口 / Grd模型 / Tin模型 / 模型应用 / 设置 / 处理点线 / 帮助`

**空间分析 `W60_Anly`**：`文件 / 窗口 / 空间分析 / 属性分析 / D3M分析 / 检索 / 转换 / 设置 / 查看 / 帮助`

**输出模式**（工程输出之后）：`文件 / Windows输出 / 光栅输出 / PostScript输出 / 设置 / 显示 / 窗口 / 返回编辑 / 帮助`

### 2.3 工具位置

| 要找的东西 | 位置 |
|---|---|
| 缩放（放大/缩小/1:1） | 图形窗口右侧竖排图标条 |
| **复位窗口 / 更新窗口** | 图形窗口内**右键菜单**（放大/缩小/移动/**更新**/上级/**复位**/清除/参数） |
| 添加图层 | 工程模式：左侧项目栏**右键 → 添加项目** |
| 保存 / 另存工程 | 项目栏右键 → 保存工程 / 另存工程 |
| 工程输出编辑 | 项目栏右键 → 工程输出编辑 |
| 修改当前层 | 菜单 `图层 → 改当前层`(717) |

对话框坐标**每次都变**，不要写死：先用 `EnumChildWindows` 打印控件的 `id/class/rect/text` 再操作
（`scripts/drv.ps1` 的 `dlg` 动作即此）。

## 4. 各步骤要点

### 4.1 `.det` 数据文件

```
NotGrid,,
375.668798,9.390813745,0.3
```

- 必须用 **Excel 另存为 CSV**，手写文本会被判"不可识别的ASCII数据文件!"
- 读入时类型选 **所有数据文件(\*.\*)**，否则按点文件解析报"该文件非本系统文件"

### 4.2 网格化

参数按数据范围自动生成（本实验 101×163，间距 3.0534 / 3.066543 km，距离幂函数反比加权）。

### 4.3 等值线阈值

`C = X̄ + 2S`（Tukey 剔除后）。两套分带：

| 方案 | 外带 | 中带 | 内带 |
|---|---|---|---|
| ① | C | 2C | 4C |
| ② | C | 4C | 16C |

对话框填 **4 个层值**：`C / 中带 / 内带 / 数据最大值`（封顶值让最高级闭合）。
内带阈值超过网格最大值时（如 Cu 16C=155 ＞ max 140.8）填个大于 max 的占位值，该级自然不出现。

### 4.4 配色（白底+三级）

第 1 行必须设成**白色** = 低于异常下限的背景留白。实测色号：

| 元素 | 背景 | 外带 | 中带 | 内带 |
|---|---|---|---|---|
| W | 白 #264 | 浅粉 #180 | 粉 #181 | 深粉 #185 |
| Cu | 白 #264 | 浅黄 #136 | 橙 #153 | 红 #175 |
| Sn | 白 #264 | 浅薄荷 #84 | 青绿 #73 | 深绿 #90 |

色盘是自绘窗口，**位置和滚动每次不同**，必须按色号扫描（`scripts/setcol.ps1`）。

### 4.5 综合异常图

主成矿元素做面色填充，共生元素只画边界线（取消"等值线套区"、只留线）：

| 角色 | 元素 | 表现 |
|---|---|---|
| 主元素 | W | 白+三级粉填充 |
| 共生 | Sn | 红色粗线（色号 175，线宽 2-3） |
| 共生 | Bi | 青色线（色号 67） |
| 共生 | Mo | 绿色线（色号 89） |

共生元素的圈定级别要单独定：外带常把弱晕圈进来（Sn 用 7.91 会圈出一条南北向长尾巴），
按中带/内带更干净。选哪个级别先用脚本模拟（`scripts/grid_filter.py`）。

### 4.6 工程与出图

1. `文件 → 新建工程` → 地图参数确定 → **定制新建项目内容勾"不生成可编辑项"** → 确定
2. 项目栏右键 → **添加项目** → 顺序：`面 → 线 → 点 → 共生元素边界线`
3. 项目栏右键 → **保存工程**（工程名 = 成果名）
4. **图面右键 → 复位窗口** ← 不做这步，"工程输出"点了没反应
5. 点菜单栏 **工程输出**，菜单切到输出模式
6. `文件 → 页面设置` → 版面定义选 **系统自动检测幅面**（默认 A4 会把图裁成局部）
7. `光栅输出 → 生成JPEG图像`(32982) → 分辨率 **300** → 确定

### 4.7 区文件整理（合并三级异常 / 删除弱异常）

前提：`工作区` 菜单只在**图形窗口激活时**出现。

1. 打开 `.WP` → **点一下图形窗口**（菜单栏多出"工作区"）
2. 工作区 → 装入区文件(107) → 状态栏应变 `当前图层[区](启用)`
3. 区编辑 → 选择区(32844) → Ctrl 逐层点选同一异常的三级区
4. 区编辑 → 区编辑… → **合并区**(32808)
5. 区编辑 → 区编辑… → **删除区**(415) → 图上逐一点击弱异常
6. **右键 → 更新窗口** ← 不刷新等于白删
7. 工作区 → 换名存区文件(110)

### 4.8 点对区统计

空间分析子系统：装点(32771) + 装区(32773) → 空间分析 → 点空间分析 → **点对区相交分析**(32828)
→ 「选择叠加文件」1=点、2=区 → 另存 `PT_W.WT` → 属性分析 → 浏览属性数据(32855)
→ 属性输出 dbf → Excel 按区号 `MAX`/`AVERAGE`。

统计量：异常下限、峰值(MAX)、平均强度(AVERAGE)、衬度(=平均/下限)、
面积(图上面积×50×50/10⁶ = km²)、规模(=衬度×面积)。


## 6. 常见坑

详见 `references/pitfalls.md`（21 条实测）。最要命的几条：

| 现象 | 原因 | 处理 |
|---|---|---|
| 点"工程输出"没反应 | 没先复位窗口 / 有隐藏模态框 | 复位窗口；`use:<hwnd>;btn:1` 点掉隐藏框 |
| 输出只出局部或横向 | 页面设置不是自动检测幅面 | 文件→页面设置改自动 |
| 色盘选色不准 | 位置/滚动每次不同 | 按色号扫描（setcol.ps1） |
| 层值被改成乱数据 | 色盘没开时点击落到层值列 | 改色前 `findtitle:选择颜色` 确认 |
| **删区点了没反应** | 删完没刷新图面 | 右键 → **更新窗口** |
| **找不到"工作区"菜单** | 图形窗口没激活 | 点一下图形窗口 |
| 区编辑全部无效 | 当前图层是"点" | 工作区→装入区文件(107) |
| 合并后存不下来 | 文件→保存 对 .WP 不写盘 | 工作区→存区文件(109)/换名存(110) |
| .det 读不进去 | 手写文本/类型不对 | Excel 另存 CSV，选"所有数据文件" |
