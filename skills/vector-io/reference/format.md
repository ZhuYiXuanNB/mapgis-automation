# MAPGIS 6.7 矢量文件字节结构（本项目实测补全版）

> 与仓库 `docs/binary-format.md` 互为印证；本文补全了**注记点/文本池**、**属性描述符**、
> **线文件 8 个索引段**这些原文档缺的部分。所有偏移均为 0 基、小端。

## 0. 顶层骨架

```
0 .. 656      657 B 文件头
657 .. 816    16 × 10 B 索引区
817 ..        数据段（按索引顺序紧密排列）
```

索引项：`<int32 start><int32 volume><2B 0xFFFF>`

| 偏移 | 类型 | 内容 |
|---|---|---|
| 0–7 | char[8] | 魔数：`WMAP\`D22` 点 / `WMAP\`D21` 线 / `WMAP\`D23` 面 |
| 8–11 | i32 | 文件标识：点=1、线=0、面=2 |
| 12–15 | i32 | 索引区起始（实测恒 657，但要读不要写死） |
| 109 | u8 | 投影类型（0=经纬度 5=高斯 2=aea 3=lcc） |
| 110 | u8 | 椭球号（1=克氏 2=西安80 7=WGS84 16=克氏） |
| 143–150 | f64 | 比例尺分母 |
| 244–251 / 252–259 | f64 ×2 | **毫米→度系数**（为 0 时符号尺寸归零、全图不显示） |
| 260 | u32 | 图元数 n |
| 264 | u32 | n + 1 |
| 304–335 | f64 ×4 | 图幅边界框 xmin,ymin,xmax,ymax |
| 336 | u8 | 类型标志（点 0x80、线 0） |

> 结论：**头要从真实文件克隆**。自己拼的头常常差在 244/252 与 304 上，MapGIS 不报错但不出图。

### 1.1 点记录 93 B

| 偏移 | 类型 | 子图点 | 注记点 |
|---|---|---|---|
| 0 | u8 | 1 | 1 |
| 1–2 | u16 | — | **文字字节数** |

| 7–14 | f64 | X | X |
| 15–22 | f64 | Y | Y |

| 37 | f32 | 高 mm | 字宽 mm |
| 41 | f32 | 宽 mm | 字间隔 mm |
| 45 | f32 | 旋转角 | 旋转角 |

| 51 | u8 | — | 西文字体 |
| 53 | u8 | — | 字形 |
| 75 | u8 | 颜色号 | 颜色号 |

> 子图号是 `i16 @33`，与注记点的 `f32 字高@33` 重叠——**同一个位置两种解释**，由 `@31` 的点种类区分。

### 1.2 文本池

```
[0 .. 1601]   样式前缀（1602 B，克隆真实文件；两份真实样本仅 68 字节不同）
[1602 ..]     GBK 文字首尾相接，偏移即"从池首算起的字节位置"
```

实测：`地质.WT` 池 1855 B（27 条，253 B 文字）、`图框.WT` 池 1923 B（138 条，321 B 文字）。
两条真实样本的字符串区都恰好从 1602 开始，所以 1602 是**固定前缀长度**，不是"首条偏移"。

### 1.3 标注框

`(xmin, ymin, xmax, ymax)` 四个 f64。注记点的框按
`(x, y-0.35h, x + 字宽, y + 0.95h)` 估即可（锚点=文字左下角）。
缺失或全零 → MapGIS 可能"能读不显示"。

## 3. 面文件 `.WP`（摘要）

| 索引 | 内容 | 记录长 |
|---|---|---|
| 0 | 弧索引 | 57 |
| 1 | 坐标（+ 结点表） | 2B 前导 |
| 3 | 拓扑 | 24 |
| 8 | 区参数 | 40 |
| 9 | 属性 | 变长 |
| 10 | 区标注框 | 32 + 32n |
| 12 | 文件脚 | 4 + 4n |

- 拓扑 24 B：`[i32 结点a][i32 结点b][i32 左区][i32 右区][8B 0]`，区号从 1 起
- 区参数 40 B：`kind@0=1`、**类码@1=图层（0 不显示）**、填充色@5、图案@6、图案色 u16@9
- **段 10、12 缺失 → 区能解析但永不渲染**（实测）

## 4. 属性表（三类文件共用）

```
[0..321]     322 B 前缀（@0 与 @320 为 `D 签名，@2 日期，@20+ GBK 工作目录）
[322]        i16 字段数 nf
[324]        i32 记录数 nr（= 图元数 + 1）
[328]        i16 记录长 rl
[330..347]   18 B 填充
[348..]      39 B × nf 描述符
[348+39nf..] 记录区：nr × rl
```

### 4.1 字段描述符 39 B（`<20sBihhih4x`）

| 偏移 | 类型 | 含义 |
|---|---|---|
| 0–19 | char[20] | 字段名（GBK，\0 结尾） |
| 20 | u8 | 类型 0串 1byte 2short 3int 4float 5double 6日期 7时间 |
| 21 | i32 | 记录内偏移（首字段=1，因为第 0 字节是 0x01 标志） |
| 25 | i16 | 存储宽度 |
| 27 | i16 | 声明宽度（串=容量，数值=15） |
| 29 | i32 | 标志（串=256，数值=512+小数位） |
| 33 | i16 | 字段序号 |

### 4.2 记录

每条 `rl` 字节，`[0]=0x01`，之后按描述符偏移放值；串右补 `\0`。

> 记录长 `rl` 必须等于 `1 + Σ各字段存储宽度`；对不上 → MapGIS 里字段整体错位。

## 5. 校验清单

- 魔数对不对（`.WT`=`WMAP\`D22`）
- `n = idx0.volume / 记录长 - 1`
- 首条记录是否为空
- 属性 `nr == n + 1`、`rl == 1 + Σ宽度`
- 注记：文本池 `= 1602 + Σ文字字节数`；框表 `(n+1)×32`；标志 `4+4n`
- 头部 244/252 非零、304 边界框非零
